# মোঃ আবু তাহের — মহাদান ইউনিয়ন প্রচারণা প্ল্যাটফর্ম

মহাদান ইউনিয়নের চেয়ারম্যান পদপ্রার্থী **মোঃ আবু তাহের**-এর জন্য একটি আধুনিক, মোবাইল-ফার্স্ট
প্রচারণা ও নাগরিক সেবা প্ল্যাটফর্ম। পুরোনো সাইট (`mdabutaher.com`) এর কনটেন্ট ও কাঠামো
নতুন ডিজাইন সিস্টেমে পুনর্নির্মাণ করা হয়েছে, সাথে যোগ হয়েছে সম্পূর্ণ নতুন সেবা ও CRM।

## দ্রুত শুরু

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # প্রোডাকশন বিল্ড
npm run typecheck
```

ডেটা ডিফল্টভাবে `data/db.json`-এ থাকে (প্রথম রিকোয়েস্টে স্বয়ংক্রিয়ভাবে তৈরি)। প্রোডাকশনে
`MYSQL_HOST` / `MYSQL_DATABASE` দিলে হুবহু একই `read()` / `mutate()` কনট্র্যাক্ট নিয়ে
**MySQL/MariaDB** ব্যবহার হয় — আলাদা কোড বদলাতে হয় না। বিস্তারিত: [`docs/08-DEPLOY-CPANEL.md`](docs/08-DEPLOY-CPANEL.md)।

### অ্যাডমিন লগইন
- কমান্ড সেন্টার + CRM: `/admin` → ইউজারনেম `admin`, পাসওয়ার্ড `mahadan-2027`
  (প্রথম অ্যাকাউন্ট তৈরি হয় `ADMIN_USERNAME` / `ADMIN_PASSWORD` env থেকে; এরপর সেটিংস →
  ব্যবহারকারী ও ভূমিকা থেকে আলাদা অ্যাকাউন্ট খুলুন)
- কমান্ড সেন্টারে প্রকাশিত `news` / `event` / `blog` পোস্ট স্বয়ংক্রিয়ভাবে পাবলিক
  `/news`, `/events`, `/blog` এবং হোমপেজের নিউজ টিকারে যুক্ত হয়।
- **সাইট কনটেন্ট** (কমান্ড সেন্টার → সাইট কনটেন্ট): সব মেনু/সাব-মেনু পেজের শিরোনাম,
  বর্ণনা, অতিরিক্ত লেখা, ছবি, ভিডিও ও দৃশ্যমানতা এক জায়গা থেকে সম্পাদনা। সংরক্ষণের সাথে
  সাথে পাবলিক পেজে দেখা যায় (`revalidatePath`)।
- **হোমপেজ সেকশন**: হোমপেজের ১২টি ব্লকের eyebrow/শিরোনাম/বর্ণনা ও দৃশ্যমানতা।
- **গ্যালারি ছবি ও ভিডিও**: ছবি/পোস্টার/ভিডিও যোগ, ক্যাপশন-ট্যাগ সম্পাদনা, আপলোড,
  লুকানো/ফিরিয়ে আনা। কিউরেটেড আইটেম কখনো মোছা হয় না — শুধু লুকায়।
- **কনটেন্ট স্টুডিও**: ব্লগ/সংবাদ/ইভেন্ট পোস্টে রিচ টেক্সট এডিটর (শিরোনাম, তালিকা,
  উদ্ধৃতি, লিংক, ইনলাইন ছবি আপলোড) + কভার ছবির আপলোড/লাইব্রেরি।
- **ইভেন্ট ও ম্যানিফেস্টো**: প্রতিটি ইভেন্ট এবং প্রতিটি স্তম্ভ/অঙ্গীকার আলাদাভাবে
  সম্পাদনা ও লুকানো — অগ্রগতি স্লাইডারসহ।
- **নিউজ টিকার**: হেডারের চলমান খবর চালু/বন্ধ, অটো (সংবাদ+ইভেন্ট+ডিফল্ট) বা নিজের
  তালিকা, প্রতিটি লাইন যোগ/সম্পাদনা/সাজানো/লুকানো/মুছে ফেলা — রিডিপ্লয় ছাড়াই।
  ব্লগ/সংবাদ তালিকার কার্ডে কভার ছবির থাম্বনেইল প্রিভিউও এখন এডিটরে দেখা যায়।
  বিস্তারিত: `docs/05-CONTENT-GUIDE.md`।

## GitHub Pages প্রিভিউ

পাবলিক সাইটের একটি **স্ট্যাটিক মিরর** GitHub Pages-এ প্রকাশিত হয়:
<https://taherdeshik.github.io/mdabutaher/>

```bash
node scripts/build-ghpages.mjs --publish   # মিরর তৈরি করে ব্রাঞ্চ রুটে প্রকাশ করে
```

- Pages (legacy mode) এই ব্রাঞ্চের রুট ফোল্ডার সার্ভ করে, তাই আউটপুট রুটে কপি হয়;
  কোন ফাইল তৈরি হয়েছে তা `.ghpages-manifest.json`-এ থাকে এবং পুরোনো পেজ স্বয়ংক্রিয়ভাবে মুছে যায়।
- মিররে **ফর্ম, পোল, চ্যাট ও অ্যাডমিন নেই** — সেগুলোর জন্য Node + MySQL সার্ভার লাগে
  ([`docs/08-DEPLOY-CPANEL.md`](docs/08-DEPLOY-CPANEL.md))।
- Pages সেটিংসে Source = GitHub Actions করা হলে `--publish` ছাড়াই CI থেকে ডিপ্লয় করা যাবে।

## ডিজাইন সিস্টেম

- **রঙ:** `night` / `forest` / `emerald` / `gold` / `cream` — সব `src/app/globals.css`-এ `@theme` টোকেন।
- **কম্পোনেন্ট:** `src/components/ui/*` — Button, Section, Reveal, Counter, SmartImage, Accordion, PageHero, Form।
- **মোশন:** সব অ্যানিমেশন `prefers-reduced-motion` মানে।
- **অ্যাক্সেসিবিলিটি:** স্কিপ লিংক, ফোকাস রিং, ARIA লেবেল, সেমান্টিক হেডিং।
